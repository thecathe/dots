# dots: options reference

Every option `thecathe/dots` declares under `dots.*`, one page for each module set:

- [options-home.md](options-home.md): `homeModules.default` (home-manager)
- [options-nixos.md](options-nixos.md): `nixosModules.default` (NixOS)

These pages are generated by a GitHub Action
(`.github/workflows/options-reference.yml` on `main`) on every push to `main`, from the
modules' option declarations, and published here. Do not edit them: change the option's
`description` in the module named under "Declared by", on `main`. To build the same pages
yourself: `nix build github:thecathe/dots#options-reference`.
